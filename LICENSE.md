This site mixes third-party data with original writing, and the two carry
different terms. The split is below.

## Stroke-order data — CC BY-SA 3.0 (inherited, not chosen)

`assets/kana-data.js` contains stroke paths extracted from
**[KanjiVG](http://kanjivg.tagaini.net)**, Copyright © Ulrich Apel, released
under [Creative Commons Attribution-ShareAlike 3.0](https://creativecommons.org/licenses/by-sa/3.0/).

That data is used here unmodified in substance — only reformatted from one SVG
file per character into a single JavaScript object, and paired with vocabulary.
Because CC BY-SA 3.0 is a share-alike licence, **this derived file must stay
under CC BY-SA 3.0**, and anyone reusing it must attribute KanjiVG and link to
<http://kanjivg.tagaini.net>. Attribution is carried in the file header, in the
footer of every page that renders a stroke, and on the reference sheet.

The same applies to `assets/kana-chart.js` and `assets/kana-grid.js` insofar as
they render that data.

## Dictionary data — CC BY-SA 4.0 (inherited)

The word list in `assets/vocab-data.js` was built against
**[JMdict/EDICT](https://www.edrdg.org/jmdict/j_jmdict.html)**, © the
[Electronic Dictionary Research and Development Group](https://www.edrdg.org/),
used under [Creative Commons Attribution-ShareAlike 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
and reached through [Jisho.org](https://jisho.org/). Every reading, every English
sense and every "also means" note was checked there, and JMdict's `common` tag
decided which words were allowed in at all — so some short glosses inevitably
follow its wording. That licence is the same one the rest of this site uses, so
nothing further is required beyond the attribution here and on the pages
themselves.

stays under one compatible family — CC BY-SA 3.0 material can be combined into a
BY-SA 4.0 work, but not into an MIT or CC0 one.
