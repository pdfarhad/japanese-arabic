# Japanese &amp; Arabic, side by side

A public learning log. I started Japanese from absolute zero in July 2026 — I
could not read a single character. Alongside it I am closing a gap I have carried
for years: I read and pronounce Arabic accurately but never understood it.

So every Japanese sentence I learn gets translated into Arabic too. The Japanese
supplies the situation, the Arabic supplies the meaning I was missing, and one
set of sentences teaches two languages.

**Read it here: https://pdfarhad.com/learning/japanese/**

## How it works

My teacher hands out lecture notes. Each day's notes become one lesson — not a
copy of the notes, but the same material plus the things paper cannot do:

- **Stroke-order animation.** Tap any hiragana and it draws itself, one numbered
  stroke at a time, in the order a Japanese reader expects.
- **Audio in both languages.** Every phrase has a play button for the Japanese
  and another for the Arabic.
- **A drill that asks back.** Some things are only learned by being asked which
  one this is. Lesson 3 shows a character with no romaji and no audio, and hands
  you the explanation when you miss it; lesson 4 does the same for whole words,
  and will run the question backwards — English to Japanese, or Japanese
  straight into Arabic — if you ask it to.
- **Printable reference sheets.** The compressed version of each lesson, made to
  sit beside the paper.

The Arabic is Modern Standard Arabic with full harakat — deliberately, since
decoding the script was never the problem.

## About the audio

Every 🔊 button uses your **browser's own speech voices**. Nothing is downloaded
and no server is involved, which is why this works as a plain static site. If a
button looks faded, your device has no voice installed for that language — on
macOS you can add one under System Settings → Accessibility → Spoken Content →
System Voice → Manage Voices.

Synthesised speech is a good approximation but gets Japanese pitch accent wrong.
For that, trust [NHK's Easy Japanese](https://www.nhk.or.jp/lesson/en/)
recordings over this site.

## Corrections welcome

I am a beginner in one of these languages and a non-speaker in the other, so
mistakes are likely. **Please open an issue** if you spot one — especially on the
Arabic. "Grammatical but nobody says it that way" is exactly the kind of thing I
cannot catch myself.
